# PPT 汇报

## 母版优先

- 编辑现有材料时先检查页序、画布、母版、版式、字体和关键元素，再修改工作副本。不要覆盖只读原模板。
- 用户提供可使用的母版时，新建页面优先使用实际存在的内置版式；按名称和占位符含义匹配，不硬编码某个私有版式名或页号。
- 本包提供213页原生PPT素材供选型复用。用户没有指定母版且无合适模板页时，使用公开 PPTX 编辑库或演示应用创建 16:9 文稿，建立统一页头、页脚、文字层级与留白；不要因模板缺失而阻塞任务。
- 使用程序构建时，把重复页头、页脚和坐标封装成公共函数或公共版式，避免逐页手抄。不要宣称一个公共函数等同于真实 PowerPoint 母版。
- 版式只决定内容区结构，不覆盖用户母版或已确定的视觉系统。HTML 和 PPTX 共享页序、内容逻辑和模块相对坐标；按[布局契约](layout-contract.md)映射几何，分别渲染，不承诺逐像素或交互无损互转。

## 可编辑性

- 标题、正文、表格、简单图示尽量使用原生可编辑对象。数据图表优先原生图表及其嵌入数据，不用整页截图覆盖内容。
- 复杂插画可以是图片，但说明可编辑范围。不能仅把 HTML 截图放进 PPT 后声称“可编辑 PowerPoint”。
- 对包含动画、SmartArt、复杂母版、媒体或特殊对象的现有文件，选择保真编辑路径。使用库重存前检查它会不会丢失不支持的对象；有风险时保留原文件并说明限制。
- 原始数据没有给出的数字、目标或行动责任人不能补造。报告中的建议必须与已确认行动区分。

## 样式与结构

- 新建材料默认公司蓝/深灰为主、灰黑白辅助；按视觉规范少量自主选用辅助色，HTML/PPT整稿一致。已有绿色或其他主题除非用户要求更换，否则保留。
- 固定四级默认字号：页标题27pt、核心主张19pt、模块标题16pt、正文以12pt为主。用户提供TencentSans W7/W3时，中英文保持统一；未提供时说明实际采用的字体，不冒充指定字体。表格仍为12pt；过密先拆页或放附录。
- 先按摘要索引选1–3个候选，再对比预览和原生对象；确认后复制所选模板页并改内容。保留母版结构、组合、关系和裁切；按锁定色盘映射颜色角色，检查母版/主题继承色与显式RGB。用户指定原样复刻时才保留源配色。数量图形随数据重新计算。
- 标题、主张、模块标题、正文位置遵循布局契约；先稳定HTML模块坐标，再按PPT尺寸映射并应用PPT字号。字体WOFF2不能直接当作PPT桌面/嵌入字体。
- 标题交代判断，证据支持判断，总结不重复标题。相同框架不得连续三页出现。
- 风险或警示色依据内容选择，并有文字标签；不把正常在途或单纯待确认项自动标为风险。

## 制作路径

1. 复用环境已有的 PPTX 格式工具、PowerPoint、LibreOffice 或公开编辑库。使用前确认实际可用性和版本，不假设包已安装。
2. 需要编程创建时，可选 `python-pptx` 或 `pptxgenjs`；选定一个即可，不为简单任务装全套工具链。安装前说明用途并使用隔离环境。
3. 采用底层 XML 编辑时，同时维护关系文件、内容类型、版式和页序；仅有合法 ZIP 不代表合法 PPTX。复杂合并优先使用支持该操作的工具。
4. 在临时输出目录生成结构检查与渲染结果；保留用户主文件，不覆盖同名无关文件。

## 检查

- 运行 `python3 scripts/check_delivery.py output.pptx` 检查包内基本结构、关系目标、宏/嵌入对象和可疑元数据提示。该检查不证明格式完全合规或内容可编辑。
- 使用实际演示应用或可用渲染器渲染，逐页检查字体、换行、溢出、重叠、对齐、空白占位符、页码和颜色一致性。
- 新建文件检查所有页；局部编辑检查修改页，全局母版或字体修改检查全部受影响页。
- 在实际 PPTX 中验证文本/表格/图表可编辑，不能只凭渲染图判定。检查页序以及改动范围外内容未丢失。
- 缺少渲染条件时如实列出未完成项目；结构检查通过不可写成“逐页视觉检查通过”。
