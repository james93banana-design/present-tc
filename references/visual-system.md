# 视觉与表达

## 公司基础色盘（HTML / PPT 必读）

依据用户提供的“腾讯新视觉系统配色方案”及2026-11-03的收窄要求，固定主色为蓝色与深灰，补充中性灰、黑、白。按图上标注的HEX/RGB录入，不从截图显示色取样。用户写的 `5358F` 按参考图完整值 `#53585F` 处理。本技能是个人项目，采用用户提供的公司色盘不代表官方维护或背书。

制作前先锁定整稿色盘。用户本次明确指定优先；已有确认稿在局部修改时保留原主题；新稿默认以下基础色盘。模板参考页与图表库默认主题不构成已确认主题。精确值由 `assets/report-tokens.json` 的 `colors` 统一管理：

| 角色 | token | 色值 |
|---|---|---|
| 主蓝：标题、重点、按钮、核心系列 | primary | `#0052D9` |
| 主深灰：正文与主要信息 | text | `#53585F` |
| 次级正文：以字重和层级区分 | textSecondary | `#53585F` |
| 辅助灰：弱信息、辅助图形 | muted | `#97A4AD` |
| 浅灰：边框、分隔线 | border | `#D7D7D6` |
| 浅灰分区基色，可降低填充不透明度 | surfaceMuted | `#D7D7D6` |
| 页面白底 | page | `#FFFFFF` |
| 白色底板、反白字 | surface | `#FFFFFF` |
| 纯黑：必要的高对比文字、计时黑字 | black | `#000000` |

蓝与深灰建立主层级，中性灰辅助，白色提供留白。浅灰不用于关键正文；检查小字与背景对比，不以颜色代替标签。轻背景可由基础色低透明度叠加在白底生成，但不得借此另造一套主色或把已有封面压暗。局部改字不改背景、渐变、蒙层与亮度。

## 辅助色：保留模型判断空间

- 图中的青、绿、橙暂不纳入固定色盘，不预设为系列2/3/4；也不新增其他固定高饱和亮色。
- 模型可按内容自主少量选择辅助色：确有多系列区分、风险提示或重点对照时，通常补充1–2种协调、克制的颜色；不要求为正常选色逐项询问用户。
- 先定义本报告的辅助色及角色，在整稿和HTML/PPT间一致复用；同一对象同色，不因换页、换版式或换库随机换色。基础蓝/深灰仍主导，不把每个卡片涂成不同亮色。
- 数据系列优先从 `colorPolicy.chartSeries` 起步，结合直接标签、线型、纹理、边框或小图；需要扩色时按上条处理，不让模型为遵守色表牺牲可区分性。
- 风险色按实际含义选择并配文字，待确认或正常在途不自动标红。既有倒计时警示红在 `functionalColors.timerWarning` 中单独保留，仅用于落后/到时状态，不属于公司基础色盘或通用装饰色。

## 模板映射与实现

213页原生素材含酒红、灰绿及Office多色主题，只提供版式与颜色角色，不能直接作为新稿色盘。原始素材和预览保留不动；复制所选页到目标稿后，统一映射形状、表格、线条、文字、图表的颜色。检查母版继承、主题accent1–6、schemeClr、显式RGB、色阶与chart style，不能只换标题色。用户要求原样复刻时遵从该要求。

照片、截图、Logo、既有封面插画保留原色；它们不扩展正文基础色盘，不做全局图片换色。

HTML内嵌 `assets/html/palette.css`，再接壳层、编辑器、计时器和页面样式。基础色引用 `--tc-*`；报告自选辅助色在根节点集中定义并注明语义。Shadow DOM继承变量，不在每页或 `:host` 重设默认色。SVG和JS图表读取同一映射。PPT使用同一基础色与报告辅助色映射，检查主题色和显式色都已应用。

交付前逐项核对新增/改变的色值和角色，覆盖封面、正文、图表、表格、SVG、侧栏及编辑状态。已有稿只复核本次受影响颜色，不批量重染原稿。`python3 scripts/sync_palette.py --check` 仅检查技能自带默认值一致性，不限制模型为报告选择辅助色，也不代替成稿渲染。

## 字体与授权

- 本次个人配置默认中文使用TencentSans W3/W7；标题和强调W7、正文W3。覆盖图表、数字、SVG和模块内部规则。完整包包含W3/W7 WOFF2字体；HTML使用随附字体，PPT检查桌面字体是否可用，缺字或资源缺失要明确说明，不静默回退冒充腾讯体。
- 中文HTML明确绑定用户提供并内嵌的W3/W7；不得在中文页面通过Arial/system-ui等独立规则绕过。英文独立版本沿用已确认设置，语言切换后重新检查。
- PPTX 明确指定实际可用的字体。中英文、符号和数字需要一起检查；未安装字体可能发生静默回退。
- 标题、主张和模块标题使用 `TencentSans W7`；主体使用 `TencentSans W3`。不额外搜集或加入无关字体文件。
- 安装许可不等于嵌入或再分发许可。跨设备严格一致时使用已获准嵌入的字体或说明替代方案。

## 密度与层级

- 新建 PPT 默认 16:9；已有画布比例不擅自更改。使用统一页边距与对齐线，标题、正文、注释的层级稳定。
- PPT默认28/20/16/14pt；中文HTML默认44/32/28/20px，分别对应页标题、主张、模块标题、正文。HTML正文默认20px，信息密集页允许18px，表格默认18px。两个格式各自配置，不机械换算字号。
- HTML在1280×720逻辑画布上固定字号和模块位置，外层统一等比缩放。侧栏独立，不能多层padding或max-width把内容挤成中间一小块。按布局契约映射PPT位置；无意义的副标题下大空档减半。
- 一页一个主判断；证据较多时按逻辑分层。总结句必须提供增量信息，不能换个词重复标题。
- 同类版式不得连续出现三页。不为多样性把简单信息强行画成复杂图。

## 语气与装饰

使用自然、简洁、可口头表达的语言。清楚区分已确认事实、分析判断、建议和待确认事项，不把可能性写成共识。

避免过多胶囊标签、强阴影、无意义渐变和标题下装饰短线。动效仅提示顺序和层级，尊重减弱动态效果设置。封面可更有张力，正文保持克制；不要求每页都放图片。
