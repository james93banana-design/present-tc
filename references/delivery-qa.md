# 交付检查

## 内容与范围

- 核对标题、结论、数据、单位、期间、日期和引用，与源材料一致。
- 区分事实、判断、建议、预测与待确认项；缺失信息不能被模板默认值掩盖。
- 删减、翻译或改写不改变原意；既有用户修改和未涉及页面没有丢失。
- 清理占位文案、模板指导语和不应进入正文的内部核对过程。

## 视觉

- 阅读顺序明确，字号和留白适合实际使用场景。
- 新增/变更色逐项对照公司基础色盘与本报告定义的辅助色；排查模板酒红/灰绿、Office多色和图表默认色。保留既有封面亮度、背景与蒙层；逐页对照，不全局重染图片。
- 颜色、字重、对齐、间距与页码一致；没有截断、溢出、重叠、孤行或意外空页。
- 图表口径明确，不靠颜色单独传达意义；图示箭头与关系有依据。
- 字体具备所需字符覆盖，目标设备上的回退风险已说明。

## 格式

| 格式 | 自动或结构检查 | 必须另做的检查 |
|---|---|---|
| HTML | `python3 scripts/check_delivery.py output.html` | 浏览器、离线、桌面/窄屏、已有交互；打印按需 |
| PPTX | `python3 scripts/check_delivery.py output.pptx` | 应用打开、渲染逐页查看、原生对象可编辑性 |

路径相对于技能根目录；从其他工作目录调用时使用脚本绝对路径。检查器只读，不执行文件内的 JS、宏、外链或嵌入对象，不修复或解压到磁盘。

检查器为启发式基础检查，不能发现所有动态网络依赖、CSS 写法、字体问题或 OOXML 兼容问题。退出码 0 只表示没有发现该脚本能识别的错误，警告仍要人工复核。不要把它宣传为安全审计或完整渲染验证。

## 适量复查

新建文件完整检查；局部修改复核受影响区域；共享 CSS、主题、字体、母版、图表口径或导航逻辑变更时检查所有受影响页。已通过且没有受到影响的检查不重复。

若当前环境缺少浏览器、字体或渲染器，明确写出“已完成的结构检查”和“尚未完成的视觉/兼容检查”，不声称未执行的检查已通过。

## 外发与交付

- 外发前复核注释、备注、隐藏页面、文档属性、嵌入工作簿、隐藏 DOM、源代码和图片中的敏感信息。主画面看不见不等于不存在。
- PPTX 宏或未知嵌入对象不要执行；HTML 不加入自动上传或遥测。发现风险先说明，不擅自删改用户内容。
- 交付主版本路径和宿主提供的下载链接；不同格式确有需求时才分别交付。
- 用简短文字说明主要改动、检查结果和未决问题。不主动发布到外网、提交 Git 或推送仓库。

## 固定页面和功能验收

核对四级标题和字号、模块坐标、内容饱满度与副标题间距。全篇查中文字体（含混排数字/SVG），确认字体已加载且覆盖汉字。检查普通阅读、PRESENT、全屏拒绝回退、调整窗口、切页及返回阅读，封面图像/动画不丢失，侧栏不影响逻辑页面比例。

投屏返回验收：第6页进入→退出仍在第6页；第6页进入→翻到第8页→退出在第8页；分别测试退出按钮、Esc、原生退出全屏、全屏拒绝回退、中英文、窄窗口、封面及快速退出重进。检查恢复全部页面、目录当前项、再次进入仍是当前页，且没有旧异步回调覆盖新一轮状态。

检查右下页码常显、侧栏EDIT/CN-EN同排、分钟输入/PRESENT同排、项目名年份下置。测试编辑数值、真实拖拽、八方向缩放、文字、撤销/重做、重置模块、保存重开；声明真实可编辑范围。

计时验收：默认60；首次开始；退出/重进持续；重输相同值重置；封面隐藏但持续；第60/100页且剩25/100分钟不警示、低于25分钟才红色微闪；到时0:00；输入非法值不破坏当前时长；导出不携带运行中的计时状态。

不要把代码/数值测试代替真实指针交互验证。浏览器失败只报告实际阻塞，不能宣称验证成功，也不能无证据认定为本地Chrome的问题。
