# HTML版面饱满度与文字层级

本文件的px边距与字号只适用于HTML。PPT按 `pptx-style-reference.md` 使用独立配置；两者共用主次清晰、充分展开和有目的留白的原则。

## 优先级

固定画布保证外框稳定；本规范进一步保证画布内的内容充分展开、层级清晰。不能仅做16:9和全屏缩放就认为已达到PPT效果。以用户提供的赛事风险PPT截图为饱满度和层级参考，不机械复制其斜体、阴影、颜色或内容密度。

## 可用内容区

默认1280×720画布：左右边距各48px（约3.75%），顶部32px、底部28px。内容区宽1184px（约92.5%）。这些是新稿起点，不是要求修改所有原生模板；用户指定布局和有目的的留白可例外。

- 先检查画布外是否正确等比铺满，再检查画布内的模块布局。二者分开解决。
- 不叠加播放器边距、页面padding、容器max-width和模块外边距。不要让主内容不知不觉退到画布中央70%–75%的窄栏里。
- 标题、结论、主体图表和底部观察使用统一左右对齐线。流程图、表格和主证据区优先横向展开到内容区。
- 纵向按标题区、主体区、结论区分配明确高度，间距通常16–32px。无用途的连续空白超过画布高度约8%（58px）时必须复核原因；这是检查信号，不是强制填满。
- 不给观察区设置与内容无关的巨大margin-top或min-height，也不通过space-between把两个模块推到页顶页底。
- 可以扩大证据图表、流程节点、文字与有效模块来利用空间；不能增加装饰、复制信息或拉伸图形来凑满版面。

## 三层标题与正文

按 `typography-tokens.json` 的最新默认值使用：

| 层级 | 中文 px | 英文 px | 视觉职责 |
|---|---:|---:|---|
| 一级：页标题 | 44 | 42 | 先识别本页主题，700字重 |
| 二级：核心结论 / 风险主张 | 32 | 30 | 再识别本页主要观点，700字重 |
| 三级：模块 / 流程标题 | 28 | 28 | 区分分组与步骤，700字重 |
| 正文解释 | 22 | 22 | 支撑信息，400字重 |

标题与正文不仅靠换颜色区分，还应同时具有字号和字重差异。页标题约为正文1.9–2倍，模块标题约为正文1.27倍。字号是明确的默认层级，不是先塞内容再逐页无限缩小；过长时先改写、换行、改布局或拆页。

真正的核心结论才使用二级层级；导航式副标题、单位、英文对照或元信息不应与核心结论抢层级。整个长段落不应都加粗标红，突出主张，解释文字用正常字重。

序号可作为流程或并列结构的视觉锚点：通常72–96px，默认80px。但只在内容确有顺序/编号意义时使用；数字大不等于数据量大。用户说的标题层级不自动等同于必须添加1、2、3大数字。

## HTML 2-2 的具体检查示例

用户截图中的 Pipeline Management 页有两个问题：内容区在左右保留了较宽空白，主图与Observation之间存在较大的竖向空档；流程模块标题与说明文字差距不足，主标题也偏小。

后续重做该页时：

1. 四步流程沿统一内容区铺开，放大有效节点与模块标题，保留箭头关系。需要时加入01–04步骤编号，但不是必选装饰。
2. Opportunity Pipeline作为一个清晰模块，3×/1×为重点数字，两个对比小标题显著强于解释文字。
3. 把Observation接到主体之后，以24–32px为初始模块间距，并按整体版面复核；不得保留原来无语义作用的大空档。
4. Observation的核心风险主张提炼为短句并突出，解释文字另起正常正文层级。事实与限定条件保持完整，不因排版改变含义。
5. 先做这页的实际渲染比较，再认定规则有效。此文件是规则更新，不表示原HTML 2-2已重做。

## 验收

- 在统一缩放倍率下对比源PPT与HTML，而不是比较两个不同缩放的窗口截图。
- 首眼能分辨页标题、核心观点、模块标题和正文；不能呈现成一片接近大小的文字。
- 主要模块充分使用内容区，空白有分组、对齐或强调目的。饱满度不按有色像素占比硬算。
- 中英文分别检查，长标题和密集表格不溢出，图形不变形。允许有目的的疏朗页和章节页，不要求每一页都像密集证据页。
